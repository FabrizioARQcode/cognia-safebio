# CognIA — English Demo

This repository contains the English-language CognIA learning and critical-thinking prototype.

## Run locally
Open `index.html` in a modern web browser. The prototype runs locally and does not upload responses to a server.

## Publish with GitHub Pages
1. Create a public GitHub repository.
2. Upload `index.html` and this README to the repository root.
3. Open **Settings → Pages**.
4. Under Build and deployment, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. Wait for GitHub Pages to publish the site and use the URL it displays.

## Limitations
This is an educational/research prototype, not a clinical test or validated scientific instrument. It cannot diagnose cognitive impairment or establish that AI use causes changes in memory or learning. Responses are processed in the browser and are not sent to a server.
